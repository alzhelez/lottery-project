## 1. НОВАЯ ВКЛАДКА "ПРОВЕРКА ЧЕСТНОСТИ"

### Описание

### Расположение

`Главное меню → Инструменты → Проверка честности`

    get_methods_for_game,
    get_game_statistics,
    get_recommended_method
)

def populate_method_selector(game_slug):
    # Получить методы
    methods = get_methods_for_game(game_slug)
    
    # Получить статистику
    stats = get_game_statistics(game_slug)
    
    # Получить рекомендацию
    recommended = get_recommended_method(game_slug)
    
    # Отобразить в UI

        if method['game_specific']:
            add_to_section("recommended", method)
        else:
            add_to_section("universal", method)
        
        if method['name'] == recommended:
            set_selected(method['name'])

## 10. ДОКУМЕНТАЦИЯ ДЛЯ ПОЛЬЗОВАТЕЛЕЙ

### Пример текста справки

**"Что такое популярность билета?"**

> Популярность билета — это оценка того, насколько часто другие игроки выбирают похожие комбинации.
> 
> Популярные комбинации часто содержат:
> - Даты рождения (1-31)
> - "Счастливые" числа (7, 13, 21)
> - Простые последовательности (1, 2, 3, 4, 5, 6)
> 
> Если ваш билет популярный и выиграет, вам придется делить приз с большим количеством людей.
> Непопулярный билет имеет те же шансы на выигрыш, но весь приз достанется вам!

**"Что означает статус 'Подозрительная'?"**

> Статус "Подозрительная" означает, что игра провалила несколько статистических тестов.
> Это может указывать на:
> - Физические дефекты оборудования
> - Неравномерный износ шаров
> - Предсказуемость генератора случайных чисел
> 
> ⚠️ Это не означает, что игра точно нечестная, но требует дополнительной проверки.
