приложения корректно и что показывает честная проверка методов прогноза на реальных данных.

## 2. Проверка задач приложения

| Задача | Статус | Как проверено |
|--------|--------|---------------|
| Модальное окно загрузки всех тиражей по всем играм | Работает | E2E на моке API Столото: 4 игры, включая игру без архива («Нет архива»), прогресс по каждой игре, затем автоматическая проверка на случайность. Pytest: полная загрузка, докачка, заполнение пропусков, быстрый отказ без сети |
| Анализ всех игр на возможность предсказания | Работает | Тесты случайности с корректной калибровкой: доля ложных срабатываний ≈ 5% на 200 симулированных честных лотереях; искусственные отклонения находятся |
| Страница игры | Работает | `/games/<игра>`: ссылка `https://www.stoloto.ru/<игра>/game/`, число тиражей, период (даты и длительность), номер следующего тиража. Расписание по согласованию не выводится |
| Анализ тиражей и сравнение методов | Работает | Тест на отсутствие утечки будущего для каждой из ~80 моделей: изменение тиражей ≥ t не меняет прогноз на t. Тест на реальной закономерности: если половина тиражей повторяет прошлый, модель находит это (2,2 угаданных против 0,8) |
| Режим Бога | Работает | Тест: прогнозы мета-стратегий на общих тиражах совпадают для истории 1100 и 1200 тиражей (нет подглядывания); E2E: запуск, прогресс, сохранение, итог |

Живой API stoloto.ru из среды разработки недоступен, поэтому загрузка проверена на моке,
который отдаёт ответы в формате реального API (`tests/mock_stoloto`). Разбор всех известных
форматов ответа покрыт тестами.

## 3. Какой метод работает лучше — результаты на реальных данных

Протокол: каждый тираж прогнозируется только по предыдущим; лучший метод выбирается на первых
2/3 истории, результат показывается на последней 1/3, которая на выбор не влияла. Сравнение —
с точным ожиданием случайного выбора.

**4 из 20** (13 896 тиражей, №1–13896). Случайный выбор угадывает 1,600 числа за тираж.

* Тесты случайности: отклонений нет ни в одном поле (частоты, повторы через 1–2 тиража,
  устойчивость горячих чисел, автокорреляция сумм, пары).
* Статистика и модели: лучший на отборе метод — экспоненциальная частота (полураспад 200):
  1,623 на отборе и 1,602 на контроле (p = 0,44). Ни один из 21 метода не лучше случайного
  после поправки на множественные сравнения.
* Режим Бога (398 экспертов, включая бустинг и 300 комбинаций признаков, 2 минуты): лучшая
  на первой половине мета-стратегия на второй половине даёт 1,588 (p = 0,84).

**6 из 45 плюс** (185 тиражей): данных слишком мало. Показательно, что случайный «метод»
занимает второе место на отрезке отбора — масштаб шума больше любых различий между методами.

**Вывод.** Честная проверка не находит метода, который предсказывает тиражи лучше случайного
выбора. Это ожидаемо для честной лотереи с независимыми тиражами. В промежуточной версии
этой переработки метод «холодные, окно 100» показал p = 0,03 после поправки — и потерял
значимость, когда разрыв ничьих стал детерминированным. Эффект, который зависит от того,
как разбиваются ничьи, — случайность.

Приложение по-прежнему строит прогноз на следующий тираж (лучший метод отбора, консенсус
методов и мета-стратегия «режима Бога»), но показывает его вместе с честной оценкой точности.
Если в какой-то игре появится реальное отклонение (например, сбой генератора), тесты и
контрольный отрезок его покажут.
