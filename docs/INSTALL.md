# Установка и обновление на Windows

Коротко:

| Что нужно | Команда |
|---|---|
| Поставить с нуля | `git clone https://github.com/alzhelez/lottery-project.git C:\lottery-project` → `setup.bat` → `start.bat` |
| Обновить | `update.bat` |
| Выложить свои изменения на GitHub | `publish.bat` |

Ниже — то же подробно.

## 1. Что должно быть установлено

| Программа | Зачем | Как поставить | Проверка в консоли |
|---|---|---|---|
| **Git** | скачивать и обновлять программу | `winget install Git.Git` или https://git-scm.com/download/win | `git --version` |
| **Python 3.10+** | движок анализа | `winget install Python.Python.3.12` или https://www.python.org/downloads/ (отметьте «Add python.exe to PATH») | `python --version` |
| **Node.js 20+** | веб-интерфейс | `winget install OpenJS.NodeJS.LTS` или https://nodejs.org | `node --version` |

Консоль — «Командная строка» (`Win+R` → `cmd` → Enter). После установки любой из программ
**закройте консоль и откройте новую**, иначе Windows её не увидит.

Python и Node.js можно не ставить заранее: `setup.bat` сам предложит установить их через
`winget`. Git нужен до начала.

Для API-автотестов дополнительно: Go 1.22+ (`winget install GoLang.Go`), JDK 17+ и Maven
(`winget install Apache.Maven`) — для работы программы они не нужны.

## 2. Установка с нуля

```bat
cd /d C:\
git clone https://github.com/alzhelez/lottery-project.git C:\lottery-project
cd /d C:\lottery-project
setup.bat
```

`setup.bat` создаёт окружение Python `.venv` в папке программы, ставит библиотеки Python и
зависимости интерфейса (`node_modules`). Занимает 3–10 минут, нужен интернет.

Затем:

1. **`start.bat`** — запускает приложение. Окно консоли не закрывайте, пока работаете.
2. Откройте в браузере **http://localhost:3000**.
3. Первый раз нажмите **«Загрузить тиражи»** (или в консоли `lp.bat fetch`): скачиваются
   архивы всех игр, это 10–30 минут. Дальше докачиваются только новые тиражи.
4. По желанию — **`schedule.bat`**: задача в Планировщике Windows раз в час загружает
   тиражи, сверяет журнал и делает прогнозы (`schedule.bat 3` — раз в три часа,
   `unschedule.bat` — отключить).
5. По желанию — уведомления в Telegram: [TELEGRAM.md](TELEGRAM.md).

Остановить приложение — `Ctrl+C` в окне `start.bat` (на вопрос «Завершить выполнение
пакетного файла?» ответьте `Y`).

## 3. Обновление

```bat
cd /d C:\lottery-project
update.bat
```

`update.bat`:

1. скачивает изменения с GitHub (`git pull`);
2. обновляет библиотеки Python (если окружения `.venv` нет — создаёт);
3. обновляет зависимости интерфейса (`npm install`);
4. показывает, с какой версии на какую обновились. Что нового — в `CHANGELOG.md`.

Перед обновлением остановите `start.bat` (`Ctrl+C`). Ваши данные не затрагиваются:
тиражи, результаты, журнал прогнозов, свои призы (`data\`), настройки (`.env`)
и окружение Python (`.venv`) в git не хранятся.

Если `update.bat` пишет «в папке изменены файлы программы» — вы правили какой-то файл
программы (например, `config\games.json`). Посмотреть, какие: `git status`.
Отложить свои правки и обновиться: `git stash`, затем `update.bat`; вернуть правки
поверх новой версии: `git stash pop`.

### Если программа была распакована из архива

Папка, распакованная из архива (например, `C:\lottery-project-fixed`), с GitHub не связана.
Есть два пути:

* **Связать её** — запустите в ней `update.bat`: первый раз он спросит
  подтверждение, свяжет папку с репозиторием и заменит файлы программы версией с GitHub.
  Данные и `.env` остаются на месте. Дальше — обычный `update.bat`.
* **Поставить заново** — по разделу 2 в новую папку и перенести туда данные: скопируйте
  папку `data` и файл `.env` из старой папки в новую. `.venv` и `node_modules` не
  копируйте — `setup.bat` создаст их заново.

## 4. Выложить изменения на GitHub

```bat
publish.bat
```

Показывает список изменений, спрашивает подтверждение, делает коммит «Версия X» и
отправляет на GitHub. История репозитория сохраняется — ничего не перезаписывается.
При первом запуске Git откроет окно входа в GitHub — войдите в свой аккаунт.

После отправки на вкладке **Actions** репозитория запускаются проверки (тесты движка,
интерфейса и API на трёх языках); итоговый Allure-отчёт — в артефактах сборки.

## 5. Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `"git" не является внутренней или внешней командой` | Git не установлен или консоль открыта до установки — поставьте Git и откройте новую консоль |
| `Python не найден` / `Нужен Python 3.10 или новее` | `setup.bat` — предложит установить; или поставьте с python.org с галочкой «Add python.exe to PATH» |
| `Не удалось установить библиотеки Python` | нет интернета или его режет антивирус/прокси; повторите позже |
| Порт 3000 занят | закройте другое окно `start.bat` или программу на порту 3000 |
| Загрузка тиражей: HTTP 401/403 | API Столото требует токен — инструкция в `.env.example`, раздел «Доступ к API Столото» |
| Странные данные или ошибки по игре | `lp.bat diagnose --api` — пришлите `data\diagnose.txt` и `data\api_samples.json` |
| Ошибки при записи файлов на Windows | исправлено в 40.2.1: обновитесь (`update.bat`) |
