# Уведомления в Telegram

Бот присылает:

| Событие | Когда | Что в сообщении |
|---|---|---|
| `journal` | после загрузки новых тиражей | тираж, выпавшие числа, сколько угадал каждый прогноз против ожидаемого случайного, выигрыш в рублях |
| `auto` | после цикла автозапуска | сколько новых тиражей и сверенных прогнозов, ошибки загрузки, прогнозы на следующие тиражи |
| `godmode` | по окончании режима Бога | итог, вердикт и прогноз на следующий тираж |
| `errors` | если цикл автозапуска упал | текст ошибки |

Бот только отправляет сообщения — команд он не принимает, и никто, кроме вашего чата,
сообщений не получит. Уйдёт около 10 минут.

## Шаг 1. Создать бота

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить» / `/start`.
2. Отправьте `/newbot`.
3. BotFather спросит **имя** — как бот будет подписан в чате, любое:
   `Лотерейный анализатор`.
4. Затем **username** — уникальный, латиницей, обязательно оканчивается на `bot`:
   `alzhelez_lottery_bot`. Если занят — придумайте другой.
5. BotFather ответит сообщением с **токеном** вида

   ```
   7012345678:AAH3kz9Xc-QwErTy_UiOp1234567890abcd
   ```

   Токен — пароль от бота: никому не пересылайте и не выкладывайте. Если он утёк —
   у @BotFather: `/mybots` → ваш бот → **API Token** → **Revoke current token**, и впишите
   новый.

## Шаг 2. Вписать токен в `.env`

Файл `.env` лежит в папке программы (`C:\lottery-project\.env`). Если его нет — создайте
из образца:

```bat
cd /d C:\lottery-project
copy .env.example .env
notepad .env
```

В Блокноте найдите строку `# TELEGRAM_BOT_TOKEN=`, **уберите `# ` в начале** и вставьте
токен после `=` без пробелов и кавычек:

```
TELEGRAM_BOT_TOKEN=7012345678:AAH3kz9Xc-QwErTy_UiOp1234567890abcd
```

Сохраните (`Ctrl+S`). Важно: файл должен называться ровно `.env`, а не `.env.txt`.
Проверить: `dir /a .env*` — в списке должны быть `.env` и `.env.example`. Если создавали
через «Сохранить как», выберите «Тип файла: Все файлы».

## Шаг 3. Написать боту

Откройте своего бота: ссылка `t.me/<username>` была в ответе BotFather, или найдите по
username в поиске Telegram. Нажмите **«Запустить»** (или отправьте любое сообщение).

Без этого шага бот не может писать вам — так устроен Telegram.

## Шаг 4. Найти id чата

```bat
lp.bat telegram setup
```

Ответ:

```
Бот: @alzhelez_lottery_bot
  чат 123456789: Aleksandr (private)
TELEGRAM_CHAT_ID=123456789 записан в C:\lottery-project\.env. Проверка: lp.bat telegram test
```

Команда сама дописала `TELEGRAM_CHAT_ID` в `.env`.

* «**Чатов пока нет**» — вы не нажали «Запустить» у бота (шаг 3), или с тех пор прошло
  больше суток (Telegram хранит сообщения для бота 24 часа). Напишите боту ещё раз и
  повторите команду.

## Шаг 5. Проверить

```bat
lp.bat telegram test
```

В Telegram придёт «Лотерейный анализатор 40.x: уведомления работают ✅». То же — кнопкой
в блоке **«Автозапуск»** на главной странице приложения, там же видно состояние.

Готово: уведомления будут приходить при загрузке тиражей (`lp.bat fetch` или кнопка в
приложении), при автозапуске (`schedule.bat`) и по окончании режима Бога. Перезапускать
приложение не нужно — `.env` читается при каждой отправке.

## Настройки

Все — в `.env`:

| Переменная | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен бота (шаг 1) |
| `TELEGRAM_CHAT_ID` | куда писать (шаг 4) |
| `TELEGRAM_EVENTS` | какие события присылать, через запятую; по умолчанию все: `journal,auto,godmode,errors`. Только итоги автозапуска и ошибки: `TELEGRAM_EVENTS=auto,errors` |
| `TELEGRAM_PROXY` | прокси, если api.telegram.org недоступен (см. ниже) |

Отключить уведомления — закомментируйте `TELEGRAM_CHAT_ID` (поставьте `#` в начале строки).

Состояние в любой момент: `lp.bat telegram status`.

## Уведомления в группу

1. Создайте группу в Telegram и добавьте в неё бота (Участники → Добавить → username бота).
2. Отправьте в группе `/start@<username_бота>` — обычные сообщения бот в группе не видит.
3. `lp.bat telegram setup` покажет несколько чатов — выберите группу (id группы
   отрицательный):

   ```bat
   lp.bat telegram setup --chat -1001234567890
   ```

4. `lp.bat telegram test`.

## Если не работает

Ошибки отправки пишутся в `data\logs\telegram.log`; основная работа программы из-за них
не прерывается.

| Сообщение | Причина и что делать |
|---|---|
| `В .env нет TELEGRAM_BOT_TOKEN` | строка закомментирована (`#` в начале), файл называется `.env.txt` или лежит не в папке программы |
| `Unauthorized` | токен вписан с ошибкой (лишний пробел, кавычки, не весь) или отозван — скопируйте заново у @BotFather |
| `chat not found` | неверный `TELEGRAM_CHAT_ID` или вы не нажали «Запустить» у бота — повторите шаги 3–4 |
| `bot was blocked by the user` | вы остановили бота в Telegram — откройте его и нажмите «Перезапустить» |
| `Conflict: ... webhook` | бот подключён к другому сервису — у @BotFather создайте отдельного бота для программы |
| `Telegram не отвечает`, таймаут | api.telegram.org недоступен из вашей сети — задайте прокси |

**Прокси.** Если в браузере открывается `https://api.telegram.org` (ответ «{"ok":false…}» —
это нормально), прокси не нужен. Если нет — впишите в `.env` адрес своего прокси:

```
TELEGRAM_PROXY=http://127.0.0.1:8080
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

Для `socks5` один раз доустановите библиотеку:
`.venv\Scripts\python -m pip install pysocks`.
